# Model adapters

Adapters receive the complete native request and unchanged image bytes, never GT, selection counts or an injection target. Preserve every question. The scorer alone selects `task.question_ids`. If a model's native interface accepts one question per call, process all questions rather than silently dropping unscored questions.

## Included in this code release

| Adapter | Configuration | Scope and dependency |
|---|---|---|
| `openai_decisions` | `configs/models/openai_decisions.json` | Text and original image bytes; standard-library HTTP; `OPENAI_API_KEY`. |
| `native_http` | `configs/models/liquid_d1.json` | Liquid D1 native JSON; text only in this release. Configure a currently available API model. |
| `jev_sdk` | `configs/models/jev.json` | JEV text Choice/Noul/Score through the separately installed `typesafe_sdk`; historical SDK version 0.7.0. |
| `native_http` | `configs/models/local_server.json` | Your existing native-compatible endpoint. Image data URLs are opt-in only after checking the server's contract. |
| `kev` | `configs/models/kev.json` | Text; separately install the reviewed upstream KEV runtime and download the pinned checkpoint. FP32, torch backend, strict 8192-token encoding. |
| `bosun` | `configs/models/bosun.json` | Text; separately install compatible torch/transformers and review the pinned model's remote code. Enable `trust_remote_code` only after review. |
| `python` | `configs/models/custom.json` | User-selected local factory returning an Adapter. The example intentionally returns unsupported until you implement inference. |
| `replay` | Generated by `examples/offline_demo.py` | Offline tests or exact receipt reuse; not a new model measurement. |

The core transports and mapping code have offline contract tests. GPU model loading and paid API calls were **not rerun** while assembling this public code release. Historical experiments used isolated and sometimes incompatible upstream environments. Install their required dependencies separately; there is no claim that a single torch/transformers combination runs all models.

JEV SDK error messages and HTTP response error bodies are not persisted. The native HTTP adapter disables redirects to avoid forwarding credentials. OpenAI uses a complete JSON serialization of state, retains Choice descriptions and Score levels, maps Noul to predicate, and appends any Noul criteria verbatim. Images are sent as base64 input-image parts without resizing or recompression. The API reference checked during preparation is [Create a decision](https://developers.openai.com/api/reference/resources/decisions/methods/create); API availability and provider aliases can change.

Native Choice remains authoritative even if it differs from probability argmax. OpenAI refusals on scored questions exclude the pair; refusals on unscored questions do not. Score stays probability-weighted. Bosun exposes probabilities through its native predictor; the adapter uses the historical seed and row-ID policy to keep paired option presentation stable. These transport choices are recorded, not claimed equivalent to every historical backend.

## Historical model coverage versus portable code

`results/model_catalog.json` lists 30 published model configurations and the available public checkpoint bindings. `null` in `standalone_adapter` means that this repository does **not** yet contain a standalone loader for that model. The native server/custom adapter interfaces can connect a user-supplied runtime, but do not reproduce its prompt or readout automatically.

AutoTrust, OpenJEV, the other vision runtimes, and the remaining specialist model loaders are still undergoing extraction from experiment-specific environments. They are not bundled as unreviewed vendor trees. Complete published adapter policies and historical bindings remain available in the pinned HF `results/model_details.json`. Missing pins or adapter differences must not be filled in with guesses.

## Implement a local adapter

Use `examples/custom_adapter.py` and the `python` configuration. Its explicit `module_search_path: "."` makes repository-local code importable when invoked through the installed CLI; run it from the repository root or set that path to your module directory. Only use plugin configurations you trust, because they execute Python code. Return `Prediction(answers=..., refused=..., usage=..., model=...)`. `answers` maps IDs to native `choice`, affirmative `noul`, or weighted `score` values. Include native distributions when available. Raise `UnsupportedInput` for a known unsupported request and `InferenceError(code, retryable=True)` for a transient failure. Keep error codes free of secrets and input text.

Adapters are serial by default. Mark `thread_safe = True` only if concurrent calls are safe. Input truncation, option dropping, defense text, or model-specific prompt changes are protocol changes that must be disclosed, not silent convenience fixes. The community submission validator never imports a submitter's plugin or runs their evaluation code.
