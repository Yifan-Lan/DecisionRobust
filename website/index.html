03 / INTERPRET
What these results mean
These are deliberately difficult, model-selected sets. They measure robustness on a curated challenge, not an unbiased real-world error rate.
Read the full evaluation protocol ↗
One candidate, one paired evaluation
ASR = successful attacks / valid, clean-correct pairs. Multiple attacks from the same original each count separately. Accuracy is candidate-weighted on valid pairs; unsupported and invalid pairs are excluded.
Complete inputs. Explicit scoring.
Keep all questions in the request, including those without ground truth. Score only task.question_ids. Choice uses the native label; Noul normalizes affirmative probabilities; Score uses the probability-weighted expected value with the published tolerance.
Coverage and adapters matter
Not every model supports every task or image input. Historical image results include different inference and scoring adapters. See model bindings and the protocol before making strict model-to-model comparisons.
