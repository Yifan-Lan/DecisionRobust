# DecisionRobust visual identity

The Dr. monogram abbreviates DecisionRobust and evokes diagnosing decision reliability. The intact letters sit above a red perturbation trace: stable input, a disturbance, and a return to baseline. The red period completes the abbreviation and acts as an alert indicator.

- `decisionrobust-logo.svg`: primary dark tile, also used as `website/favicon.svg`.
- `decisionrobust-logo-light.svg`: light tile for white backgrounds.

Both files contain custom vector paths; no installed fonts are required. Preserve the aspect ratio and the red trace. Use at 24 px or larger when possible; the full wordmark is DecisionRobust.

Colors: graphite `#151C2D`, off-white `#F6F7FB`, coral `#F05A4E`.

## Hugging Face destination icon

`huggingface.svg` is the official Hugging Face mark from https://huggingface.co/front/assets/huggingface_logo-noborder.svg (retrieved 2026-10-13).
